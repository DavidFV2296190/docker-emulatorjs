PRIMARY OBJECTIVE - RESOLVED ✅
================================================================================

QUESTION: What is establishing an outbound TCP connection on port 4001 every 
          10 minutes?

ANSWER:   IPFS daemon (kubo v0.24.0-r3)

DETAILS:
- Service: InterPlanetary File System (IPFS) peer-to-peer daemon
- Port: 4001 (TCP swarm port)
- Frequency: ~10 minutes (DHT refresh, peer discovery, bootstrap reconnection)
- Purpose: Artwork distribution via P2P network
- Configuration: Initialized with 'lowpower' profile
- Location: root/etc/s6-overlay/s6-rc.d/svc-ipfs/run

SOLUTION:
  docker run -e DISABLE_IPFS=true ...

This stops all port 4001 connections while maintaining other functionality.

================================================================================
MITIGATION STRATEGIES
================================================================================

OPTION 1 - Disable IPFS (Recommended):
  docker run -e DISABLE_IPFS=true \
    -p 3000:3000 -p 80:80 \
    -v /path/to/config:/config \
    -v /path/to/data:/data \
    lscr.io/linuxserver/emulatorjs:latest

OPTION 2 - Firewall Blocking:
  iptables -A OUTPUT -p tcp --dport 4001 -j DROP

OPTION 3 - Private IPFS Network:
  - Configure custom swarm key
  - Only connects to known peers
  - Requires advanced IPFS configuration

OPTION 4 - Migrate to Alternatives:
  - gaseous-server: https://github.com/gaseous-project/gaseous-server
  - romm: https://github.com/rommapp/romm/
  - webrcade: https://github.com/webrcade/webrcade
